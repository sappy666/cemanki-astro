# Cemanki — rediseño Astro

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

### Nota de assets
Las imágenes incluidas fueron recortadas de la captura del sitio Cemanki entregada para este rediseño, porque el servidor original no estaba accesible de forma fiable durante la preparación. Reemplázalas en `public/images/` por los originales de alta resolución manteniendo los mismos nombres y el sitio las tomará automáticamente.
